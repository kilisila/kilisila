# コメントディスプレイ（YouTube ライブチャット表示アプリ）

テレビで YouTube を見ながら、手元のスマートフォンにコメント欄だけを大きく表示するための Android アプリです。ライブ配信のほか、アーカイブも再生位置を手動で合わせることで追従させられます。

---

## 最初に読んでください：検証状況と公開の可否

このプロジェクトは実機ビルドと実機テストを経ていません。作成環境に Android SDK（Software Development Kit）と Google の Maven リポジトリへの接続がなく、APK（Android Package Kit）を生成できないためです。検証できた範囲とできていない範囲を、正直に分けて記載します。

### 検証済み

- `TimeText`、`VideoId`、`ReplaySync` を Kotlin コンパイラ 1.9.24 で実際にコンパイルし、単体テストを実行して全件通過を確認しました。同じテストは `app/src/test/` に JUnit 形式で同梱してあり、`./gradlew test` で再実行できます
- `MainActivity`、`ChatActivity`、`Prefs` は、Android フレームワークの型を模したスタブに対して型検査を通し、エラーがないことを確認しました
- チャットへ注入する JavaScript は Node.js の疑似 DOM 上で実行し、構文の正しさ、送信内容、スタイル要素が二重生成されないことを確認しました
- レイアウトの XML（Extensible Markup Language）整形式、文字列・色・drawable・style の参照漏れ、ViewBinding が生成するプロパティと実 id の対応を機械的に照合しました

この過程で `ReplaySync.release()` が再生位置を巻き戻す不具合と、`activity_chat.xml` のルート id が ViewBinding の `getRoot()` と衝突する不具合を見つけ、修正しています。

### 未検証

- 実機での動作全般。特に描画、余白、タップ判定などの見た目は一度も確認していません
- **アーカイブ同期が実際に効くかどうか**。ここが最大の不確定要素です（下記参照）
- 各種端末や Android バージョンでの互換性

### Google Play での公開について

**このアプリを Google Play で公開して収益化するのは現実的ではありません。** 作り込んでから知るより先にお伝えします。

- YouTube の利用規約および YouTube API Services Terms は、公式 API（Application Programming Interface）を経由せずに YouTube のコンテンツへアクセスすること、およびコンテンツをプレイヤーから切り離して表示することを認めていません。本アプリはチャットページを WebView で直接読み込む方式のため、これに該当します
- Google Play のポリシーには、既存のウェブサイトを包んだだけのアプリを制限する規定があります。審査で差し戻される可能性が高い類型です
- 他社サービスに依存したアプリを収益化すると、指摘を受けた際の心証はさらに悪くなります。開発者アカウント自体への措置に至る場合もあります

**個人利用として自分の端末にインストールする分には問題ありません。** 本プロジェクトはその用途を想定しています。

公開を目的にするなら YouTube Data API を使う設計に作り直し、API の利用規約に沿わせる必要があります。ただしその場合は 1 日あたりの割り当てが厳しく、視聴数時間で枯れます。割り当て増加の申請と審査が前提になり、個人が広告や有料販売で回収できる規模の話ではなくなります。この方向を検討するなら、先に割り当て申請の可否を確認してから設計するのが順序として正しいです。

## 仕組み

YouTube には配信者向けの「ポップアウトチャット」ページがあります。

```
https://www.youtube.com/live_chat?is_popout=1&v=<動画ID>
```

このページは動画プレイヤーを含まず、チャットだけを表示します。本アプリはこれを全画面の WebView で開き、手元で読むための機能を足しています。同期処理を自前で書く必要がなく、スーパーチャット、メンバーシップ、カスタム絵文字なども最初から正しく表示されます。

### アーカイブの同期方式

アーカイブのチャットリプレイは、動画プレイヤーから送られてくる再生位置の通知を見て進みます。通知は次の形式です。

```json
{"event":"infoDelivery","info":{"currentTime":754.0,"playerState":1},"id":1}
```

本アプリはテレビ側の再生位置を数える仮想時計を内部に持ち、同じ形式の通知を 0.5 秒ごとにチャットページへ送り込むことで表示を進めます。利用者はテレビに表示されている再生時間を入力するだけで済みます。

**ここが最大の不確定要素です。** この通知は本来ページの親フレームから送られるもので、本アプリのようにページ自身へ送る形が受け付けられるかどうかは実機で確認する必要があります。文字列形式とオブジェクト形式の両方を送って取りこぼしを減らしていますが、動かない場合は次を確認してください。

1. `⏱` ボタンでアーカイブ同期がオンになっているか（オフだとアイコンが薄く表示されます）
2. その動画にチャットのリプレイが存在するか（配信者が無効化している場合があります）
3. 時刻を入力して「合わせる」を押した後、`▶` で再生状態にしているか

それでも進まない場合、送信先の指定方法を変える必要があります（`window.parent` を経由させる、`iframe` に包んで親から送るなど）。`ChatActivity.pushPlayerTime()` の一箇所を差し替えれば対応できるよう、その部分は独立させてあります。

## できること

- 配信 URL（Uniform Resource Locator）または動画 ID を指定してチャットを全画面表示
- ライブとアーカイブのモード切り替え
- アーカイブ操作盤：再生と一時停止、`−60` `−10` `+10` `+60` での微調整、時刻の直接入力
- 再生位置を動画ごとに記憶し、次回は続きから
- 文字サイズの拡大縮小（70〜220 パーセント、設定は保存）
- 明暗の配色切り替え
- コンパクト表示（ヘッダーと入力欄を隠して表示行数を増やす）
- **表示中は画面を自動消灯させない**
- バーを隠すと全画面表示になる
- 視聴履歴を 20 件まで記録し、ワンタップで再表示
- 画面回転してもチャットが再読み込みされない

## 画面下バーのボタン

| 表示 | 機能 |
| --- | --- |
| `A−` `A＋` | 文字サイズの拡大縮小 |
| `⏱` | アーカイブ同期の操作盤を出す／しまう |
| `↻` | 再読み込み |
| `◐` | 明暗の配色切り替え |
| `▤` | コンパクト表示の切り替え |
| `↗` | 元の配信を外部ブラウザで開く |
| `✕` | バーを隠して全画面へ（右下の `⋯` で復帰） |

## 使い方

### ライブ配信

1. テレビの YouTube で配信を再生します
2. スマートフォンの YouTube アプリで同じ配信を開き、「共有」からこのアプリを選びます
3. 手元にコメント欄だけが全画面で表示されます

### アーカイブ

1. ホーム画面でモードを「アーカイブ」にして開きます（または開いた後に `⏱` を押します）
2. テレビに表示されている再生時間を「時刻を入力」から入れて「合わせる」を押します
3. コメントがその位置から流れ始めます
4. ずれを感じたら `−10` と `+10` で詰めます

## ビルド手順

### 必要なもの

- Android Studio（Koala 以降を推奨）
- JDK（Java Development Kit）17
- Android SDK Platform 34

### 手順

1. Android Studio で `File` → `Open` から `YtChatDisplay` フォルダを開きます
2. Gradle の同期を実行します（初回はライブラリの取得に数分かかります）
3. `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)` を実行します
4. 生成された APK を端末にインストールします

コマンドラインから行う場合は次のとおりです。

```bash
./gradlew test          # 同梱の単体テストを実行
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

`adb` は ADB（Android Debug Bridge）です。

### 補足

- `gradle-wrapper.jar` は含めていません。Android Studio で開けば初回同期時に自動生成されます
- Android Gradle Plugin の更新提案が出た場合は受け入れて問題ありません

## 既知の制限

- **チャットへの書き込みはできません。** Google は WebView 内でのアカウントログインを制限しているため、入力欄は出てもログインが通らない可能性が高いです。書き込みたい場合は `↗` で外部ブラウザへ移動してください
- **メンバー限定チャットは表示できません。** 上記と同じ理由です
- **`youtube.com/@チャンネル名/live` 形式の URL は解決できません。** 動画 ID を含む URL を使ってください。YouTube アプリの共有機能なら自動的にその形式になります
- アーカイブの同期はテレビ側と自動連動しません。長時間見ていると端末とテレビのわずかな時計差で少しずつずれるため、時々 `±10` で詰めてください
- YouTube 側のページ構造が変わると、コンパクト表示の効き方が変わる可能性があります。その場合もチャット表示自体は動作します

## ファイル構成

```
YtChatDisplay/
├── settings.gradle.kts
├── build.gradle.kts
├── gradle.properties
└── app/
    ├── build.gradle.kts
    └── src/
        ├── main/
        │   ├── AndroidManifest.xml
        │   ├── java/com/tak/ytchatdisplay/
        │   │   ├── MainActivity.kt    配信の指定、共有インテント、履歴
        │   │   ├── ChatActivity.kt    チャット表示、操作盤、同期の送信
        │   │   ├── ReplaySync.kt      アーカイブ用の仮想再生時計
        │   │   ├── TimeText.kt        再生位置の表示と入力解釈
        │   │   ├── VideoId.kt         URL からの動画 ID 抽出
        │   │   └── Prefs.kt           設定値と履歴の保存
        │   └── res/
        └── test/java/com/tak/ytchatdisplay/
            ├── TimeTextTest.kt
            └── VideoIdTest.kt
```

パッケージ名は `com.tak.ytchatdisplay` です。変更する場合は `app/build.gradle.kts` の `namespace` と `applicationId`、各 Kotlin ファイルの `package` 宣言を揃えて修正してください。
